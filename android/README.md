# E.L.V.A.R. Android アシスタント

Pixel の「デフォルトのデジタルアシスタント」に E.L.V.A.R. を登録するための薄いアプリです。
中身は、デプロイ済みの E.L.V.A.R.（Web）を全画面で開く WebView と、アシスタント登録用の部品だけです。

## ビルド（GitHub Actions）
1. GitHub の Actions → 「Build Android assistant APK」→ Run workflow。
2. `url` に E.L.V.A.R. のデプロイ先URLを入れる（またはリポジトリ変数 `ELVAR_URL` に設定）。空なら、アプリが初回起動時にURLを聞きます。
3. 完了後、Artifacts の `elvar-assistant-apk` をダウンロードして解凍し、`app-debug.apk` をスマホに入れてインストールします（「提供元不明のアプリ」の許可が必要）。

## 登録
設定 → アプリ → デフォルトのアプリ → デジタルアシスタントアプリ → 「E.L.V.A.R.」。
その後、電源ボタン長押し（または設定したアシスタント操作）で起動して会話を始めます。

## 注意
- 署名鍵は `app/debug.keystore`（公開してよいデバッグ用の固定鍵）。同じ鍵なので、更新は上書きインストールできます。
- WebView の保存領域は Chrome と別です。設定（アクセストークン等）は、このアプリで一度入れ直してください。
- 画面が消えている間の常時待機（拍手）はしません。
