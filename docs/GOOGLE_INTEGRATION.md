# Google連携（カレンダー・Gmail・Drive/Docs/Sheets・タスク・連絡先）

**手順の本体は、アプリ内の日本語ページ `/google-setup/` にあります**（画面付きの案内・リンク・状態表示つき）。このファイルは、仕組みと確認状況の記録です。

## できること
| サービス | 読み取り（すぐ実行） | 書き込み（毎回、画面で「承認」） |
|---|---|---|
| カレンダー | 予定の一覧、空き時間 | 予定の追加・変更・削除 |
| Gmail | 検索、本文を読む | 下書き作成、**送信**、**ゴミ箱**へ移動 |
| Drive／Docs／Sheets | 検索、テキスト・シートの読み取り | ドキュメント作成・追記、セルの更新・追加、**ゴミ箱**へ移動、特定の1人への**共有** |
| タスク | 一覧 | 追加・完了・削除 |
| 連絡先 | 検索 | （読み取りのみ） |
| 補助 | 現在の日付・時刻（日本時間） | — |

意図的な制限：メール・ファイルの削除は**ゴミ箱に移すだけ**（約30日は戻せる）。完全削除はしない。共有は**指定した1人のGoogleアカウントだけ**（リンク共有・全体公開は不可）。連絡先は読み取り専用。

## 安全のしくみ
1. **承認の関門。** 書き込みの依頼が来ると、サーバーはまず「内容の要約」と**署名つきの許可証**だけを返します（ツール名と引数のハッシュにHMAC署名、有効2分、1回限り）。承認カードの**「承認して実行」だけ**が許可証を送り返します。引数の差し替え、使い回し、期限切れ、偽造、別ツールへの流用は拒否されます（`npm test` で確認。安全装置を壊すとテストが落ちることも確認済み）。
2. Enterでは承認されません（最初のフォーカスは「却下」）。Escで却下、2分放置でも却下。モデルがボタンを押すことはできません。
3. **プロンプトインジェクション対策。** メール本文・ファイルの中身・予定のメモは「信頼できない第三者のデータ」です。人格の指示で、その中の命令に従わず報告するようにしてあります。仮に従っても、書き込みの実行にはあなたのクリックが要ります。
4. **鍵の置き場所。** Googleの認証情報はサーバーの環境変数だけ。ブラウザには渡りません。ツールの結果は切り詰めて（メール6000字、ファイル12000字）Geminiに渡します。
5. 実行した書き込みは、サーバーの記録に `[audit]` として残ります（ツール名・危険度・短縮した引数・結果ID）。
6. いつでも解除：https://myaccount.google.com/permissions で E.L.V.A.R. を削除。

## 設定の流れ（最初に一度だけ・約15分・インストール不要）
詳細は **`/google-setup/`**（日本語）。概要：
1. Google Cloud でプロジェクトを作る。
2. 7つのAPI（Calendar・Gmail・Drive・Docs・Sheets・Tasks・People）を有効にする。
3. OAuth同意画面を作る（外部）。ブランディングを埋め（ホームページ・`/privacy/`・`/terms/` はアプリ内にあります。ロゴは入れない）、**「本番環境」に公開**（「テスト中」のままだとログインが7日で切れるはず。私の理解で、Googleの最新規則は未確認）。
4. **「ウェブ アプリケーション」**型のOAuthクライアントを作り、承認済みリダイレクトURIに `https://（アプリのアドレス）/api/google/callback` を登録。クライアントIDとシークレットを控える。
5. Vercelの環境変数に `GOOGLE_CLIENT_ID` と `GOOGLE_CLIENT_SECRET` を登録（`ELVAR_ACCESS_TOKEN` も必要）→ 再デプロイ。
6. `/google-setup/` の**「Googleにログイン」ボタン**を押し、Googleで許可 → 表示された値を `GOOGLE_REFRESH_TOKEN` として登録 → 再デプロイ。
7. 設定（歯車）→ Google連携 →「接続を確認」で「接続済み ✓」を確認。

仕組み：ボタン（`POST /api/google/connect`、アクセストークン必須）が、署名つき・10分・1回限りの `state` を付けたGoogleのログインURLを返す → Googleが `GET /api/google/callback` に戻す → サーバーが `state` を検証し、**サーバー側で**コードをトークンに交換（クライアントシークレットはブラウザに出ない）→ 更新トークンを**一度だけ**画面に表示（`no-store`、アドレスバーには残らない）。

**別の方法（上級者）：** 「デスクトップ アプリ」型のクライアントと `google-auth.mjs`（Node.js 22以上、PKCE・ループバック）。`--readonly` で読み取り権限のみ要求。
