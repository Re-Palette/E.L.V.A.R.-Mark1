2. 本サービスについて

本サービスは、1つの共通のシステムを、登録した複数の利用者がそれぞれ自分専用に使うAIアシスタントです。利用者ごとに、人格（名前・呼び方・口調・声）、記憶（会話の記録・ノート）、ファイル保管庫、外部サービスとの連携が、完全に別々に保たれます。ある利用者のデータに、他の利用者が届くことはありません。

4. 暗号化と、運営者が見られるもの

  • APIキー、外部サービスのトークン、連携アプリの秘密は、利用者ごとの鍵で暗号化して保存します（その鍵はさらにサービスの鍵で包まれます）。画面・書き出しには、名前と末尾4桁しか出ません。
  • ノート、会話の記録、ファイル、読み取った文字は、検索を可能にするため、データベース・保管庫の標準の暗号化（保存時の暗号化）のみで保存されます。したがって、運営者は、技術的にはこれらの内容を読める立場にあります。運営者は、障害対応や法令に基づく場合を除き、利用者の内容を閲覧しません。管理画面で運営者が見られるのは、メールアドレス、登録日、状態、容量や回数などの数字だけです。
  • 通信はすべて暗号化（HTTPS）されます。

5. 第三者への提供・委託先・利用者自身が選ぶAIサービス

  • 運営の委託先：データベース・認証・ファイル保管は 【Supabase（保存地域：（地域））】、ホスティングは 【Vercel】、登録時の自動化対策は 【Cloudflare Turnstile】。【メール送信を使う場合は、その事業者】。これらは運営のために必要な範囲で利用者の情報を取り扱います。外国にあるサーバーで処理・保存されることがあります。
  • 利用者自身のAIサービス（持ち込みの鍵）：本サービスは、AIの利用料を運営者が負担しません。利用者は、自分のAPIキー（Gemini などは必須、ほかに Groq・Exa・NewsData など）を入れて使います。利用者の依頼の内容（会話の文章、必要な範囲のノートやファイルの内容）は、利用者の鍵で、利用者が選んだ各社のAIサービスに送られます。その取り扱いには、各社と利用者との間の規約・プライバシーポリシーが適用されます（運営者は各社の取り扱いを管理できません）。各社の無料枠や設定によっては、送った内容が各社の改善に使われることがあります。各社の規約をご確認ください。
  • Google などとの連携：利用者が自分で作ったGoogleのクライアント（OAuth）で連携を許可した場合に限り、利用者の依頼に応じて、カレンダー・メール・ドライブなどに、利用者自身の権限でアクセスします。Googleから受け取った情報の使用と転送は、限定的な使用の要件を含む Google API サービスのユーザーデータに関するポリシーに準拠します。いつでも Googleアカウントの権限の管理または本サービスの設定から解除できます。

6. 書き込み操作の安全

メールの送信、予定・ファイルの変更や削除など、外部サービスへの書き込みは、実行前に必ず画面で利用者本人が承認した場合にのみ実行されます。

7. あなたの権利（閲覧・修正・書き出し・削除）

「設定」の「私のデータ」から、いつでも自分でできます。運営者への連絡は要りません。

  • 閲覧：保存されているデータの種類ごとに、件数・容量・中身を見られます。操作記録も見られます。
  • 修正：ノート、会話、ファイルのタグ・メモ、設定、人格、連携などを、自分で直せます。
  • 書き出し（持ち出し）：すべてのデータ（ノートはMarkdown、ファイルの原本を含む）を、zipで書き出せます。APIキーなどの秘密の値は含まれません（名前と末尾4桁のみ）。ダウンロードのリンクは24時間で消えます。
  • 削除：種類ごとの削除と、アカウントの完全削除ができます。完全削除は「すぐに削除」または「7日の猶予後に削除（猶予中にログインすると取り消せます）」を選べます。削除すると、データベースの全データ、保管庫のファイル、暗号鍵が消え、外部サービスへの連携は取り消しを試みます。
  • バックアップには、【バックアップの保持期間（例：最長7日）】のあいだ残ることがありますが、暗号化された秘密は鍵を消すことで読めなくなります。この期間を過ぎると、バックアップからも消えます。
  • 画面から行えないご請求（利用停止、第三者提供の停止、開示の求めなど）は、【連絡先メールアドレス】にご連絡ください。本人確認のうえ、【30日】以内を目安にお答えします。

9. 安全管理・事故の場合

利用者ごとにデータを分離し（データベースの行ごとのアクセス制御）、秘密を暗号化し、管理者の権限を数字の確認に限り、操作記録を残しています。個人データの漏えい等が起きた場合は、法令に従い、影響を受ける方と監督機関に遅滞なくお知らせします。

10. Cookie・端末内の保存
