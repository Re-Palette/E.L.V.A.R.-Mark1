プライバシーポリシー

E.L.V.A.R. Mark1（以下「本アプリ」）　最終更新：2026年11月1日

1. 本アプリについて

本アプリ（E.L.V.A.R.）は、オープンソースの個人用AIアシスタントです。このページはテンプレートで、ご自身でデプロイした方（以下「運営者」）が自分自身のためだけに使うことを前提に書かれています。他の方に提供する場合は、運営者が内容を書き換えてください。不特定多数に提供するサービスではなく、会員登録もありません。ここでいう「利用者」は、本アプリを自分で運用している本人（開発者と同一人物）です。

2. 扱う情報と、使う目的

利用者がGoogleアカウントの連携を許可した場合に限り、利用者の音声などによる依頼に応じて、次の情報にアクセスします。

  • Googleカレンダーの予定
  • Gmailのメール（検索・本文の読み取り・下書き・送信・ゴミ箱への移動）
  • Google Drive・ドキュメント・スプレッドシートのファイル
  • Googleタスク、連絡先（読み取りのみ）

目的は、利用者本人の依頼を実行すること（予定の確認、メールの要約、文書の作成など）に限ります。広告、販売、プロファイリング、利用者の依頼のない分析には使いません。

3. 保存

  • 上記のGoogleのデータは、本アプリのサーバーに保存しません（依頼の処理のために一時的に通過するだけです）。
  • サーバーに保存されるのは、Googleへのログイン状態を保つための認証情報（更新トークンなど）で、サーバーの環境変数として、利用者本人だけが管理します。
  • 設定や、利用者が任意で選んだ音楽ファイルは、利用者のブラウザ内にだけ保存され、サーバーには送られません。

4. 第三者への提供

  • Googleのデータは、依頼の内容を理解・要約・回答するために、会話の一部としてGoogle の Gemini APIに送信されます。
  • それ以外の第三者に、情報を提供・販売・共有することはありません。
  • 本アプリによる、Google API から受け取った情報の使用および他のアプリへの転送は、限定的な使用の要件を含む Google API サービスのユーザーデータに関するポリシーに準拠します。

5. 書き込み操作の安全

メールの送信、予定・ファイルの変更や削除などの書き込みは、実行前に必ず画面で利用者本人が承認した場合にのみ実行されます。削除はゴミ箱への移動に限り、完全な削除は行いません。

6. 連携の解除とデータの削除

  • いつでも、Googleアカウントの権限の管理から、本アプリのアクセスを取り消せます。
  • サーバーの環境変数から認証情報を削除すれば、本アプリはGoogleのデータにアクセスできなくなります。

7. 変更

本ポリシーは、必要に応じて改定することがあります。改定した場合は、このページの日付を更新します。
