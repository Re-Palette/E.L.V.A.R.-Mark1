後者は「音量」に対する割合です。挨拶や返事の声が出ている間と、マイクが開いている間、自動で小さくなります。

・拍手で始まった音楽は、既定では起動時に一度だけ流れて終わります（「ループする」をオンにすると、止めるまで流れ続けます）。途中で止めるには、アプリ下部の ■ STOP、または Esc キー（デスクトップアプリはトレイのメニューからも）。
・選んだファイルは、この端末のブラウザの中だけに保存されます。サーバーにも GitHub にも送られません。別の端末で使うには、その端末でも選んでください。
・ブラウザのサイトデータを消すと、ファイルも消えます。
